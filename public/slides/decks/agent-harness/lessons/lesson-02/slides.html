HARNESS FUNCTION 02

Tool 要从 Agent 的理解方式设计

01 / NAME

可理解

名称直接表达动作，不使用内部缩写。

02 / SCOPE

单一职责

一次调用的成功与失败边界明确。

03 / SCHEMA

参数防呆

结构化字段让错误参数难以产生。

04 / RESULT

返回可判定

成功、失败、重试与状态变化可区分。
