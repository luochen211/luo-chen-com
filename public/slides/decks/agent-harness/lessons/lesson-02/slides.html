HARNESS FUNCTION 05

先局部修复，最后安全终止

01静默重试先处理短暂超时
02接续生成从已有轨迹继续
03回退恢复上一稳定状态
04熔断连续失败停止重试
05转人工高风险或不可恢复
可靠性不是永不失败，而是失败可见、可控、可恢复，并且知道何时停止。
Harness Runtime · Refund Example
09 / 10
USER REQUEST · REFUND AN ORDER FROM THREE DAYS AGO

五个功能怎样完成一次退款

01 · CONTEXT读到退款政策签收后 7 天内可退款
02 · TOOLS查询订单query_order 返回订单与金额
03 · CONSTRAIN检查行为边界退款金额不得超过订单金额
04 · TOOLS执行退款调用 process_refund
05 · VERIFY查询数据库退款状态确实已经更新
06 · CORRECT处理 API 超时静默重试，持续失败再熔断
数据库确认成功才向用户宣布完成；工具超时不是失败结论，而是 Correct 接管的起点。
