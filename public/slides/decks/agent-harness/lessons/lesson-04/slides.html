Single vs Multi Agent · Split Criteria
04 / 09
SPLIT ONLY WHEN THE BOUNDARY IS REAL

多 Agent 不是默认升级

1 SINGLE AGENT + SKILLS
共享一套目标

上下文、权限和完成标准基本一致时，保持一个决策主体。

  • 链路短、成本低
  • 状态一致
  • 更容易评测
N MULTI AGENT
存在真实边界

专业能力、上下文隔离、权限或评测标准明显不同才拆分。

  • 需要明确交接协议
  • 要防错误级联
  • 必须单独评测路由

Failure Map · Six Recoveries
08 / 09
THE NORMAL PATH IS NOT ENOUGH

每一种失败，都要有指定出口

01

约束冲突

指出冲突，请用户决定优先级。

02

Tool 超时

有限重试，失败后显示无法确认。

03

商品缺货

淘汰候选，继续查询备选。

04

Memory 冲突

当前明确表达优先并修正旧记忆。

05

重复调用

命中循环检测，熔断并总结状态。

06

证据不足

不下结论；解释缺口或请求人工。
