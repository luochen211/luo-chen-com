Single vs Multi Agent · Split Criteria
04 / 08
THE KEY QUESTION IS INFORMATION GAIN

多 Agent 不是默认升级

1 SINGLE AGENT + SKILLS
没有新信息

如果只是让多个角色重看同一段材料，单 Agent 增加计算通常也能做到。

  • 协作不产生额外证据
  • 通信增加成本
  • 不应为了角色名而拆分
N MULTI AGENT
引入新信息

Reviewer 能获得测试结果、渲染截图或外部工具验证时，协作才有实质增益。

  • 共享或隔离上下文都可设计
  • 交接传结构化摘要
  • 评测必须覆盖协作轨迹
