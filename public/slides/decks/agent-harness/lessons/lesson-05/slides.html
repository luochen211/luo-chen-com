Evaluation Metrics · Process and Outcome
02 / 05
TRACE + OUTCOME · QUALITY + SAFETY

评测必须同时看过程与结果

01 / PROCESS

行动是否合法

工具与参数是否正确，路径是否高效，检索是否充分。

02 / OUTCOME

任务是否成功

用任务成功率、Pass@k、Pass^k 或 Best@k 衡量。

03 / ROBUSTNESS

变化下是否稳定

观察 API 抖动、页面变化、随机性和旧信息干扰。

04 / SAFETY

是否安全合规

越权、敏感操作和数据泄漏采用零容忍否决。

Evaluation Dataset · Six Design Checks
03 / 05
THE DATASET DETERMINES WHAT THE SCORE MEANS

评测集要通过六项检查

01

明确而开放

目标可复现，但允许多种合理路径。

02

真实且可控

保留现实噪声，同时能稳定复现环境。

03

分层难度

简单、中等、困难对应不同能力瓶颈。

04

客观可验证

优先检查最终环境状态，而非语言声明。

05

系统性分布

覆盖能力、难度、场景与边界条件。

06

质量与防泄漏

人工筛选、参数化变体并持续修订。
