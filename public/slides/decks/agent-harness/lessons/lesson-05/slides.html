Minimum Evaluation · Four Questions
02 / 05
PROVE THE SYSTEM, NOT THE SENTENCE

最小评测只问四件事

01 / UNDERSTAND

理解对吗

是否提取了全部硬约束与关键偏好。

02 / ACT

行动对吗

是否选择正确 Skill、Tool 与参数。

03 / VERIFY

事实对吗

价格、库存、规格是否有有效证据。

04 / COMPLETE

任务完成吗

结果是否满足约束并真正解决问题。

Test Set · Six Boundary Cases
03 / 05
A DEMO IS ONE RUN · A PRODUCT IS A DISTRIBUTION

至少覆盖六种任务变化

01

信息完整

直接搜索、过滤与比较。

02

缺关键条件

只追问会改变结果的问题。

03

约束无解

说明无满足项，不偷偷放宽预算。

04

实时变化

价格上涨或商品突然缺货。

05

历史冲突

Memory 与本轮明确需求相反。

06

系统失败

Tool 不可用时不编造答案。
