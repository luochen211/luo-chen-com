行动前

参数中

行动后

03 / 09
HARNESS FUNCTION 04

模型声称完成，不等于任务真的完成

C CLAIM
语言结论

“这款耳机 499 元、有货、支持双设备。”

  • 可能来自旧知识
  • 可能把计划当成事实
  • 不能作为最终证据
E EVIDENCE
外部证明

价格 Tool、库存 Tool、商品规格字段返回一致。

  • 来源明确
  • 时间有效
  • 可再次查询验证

DO NOT MIX THE LAYERS

四类信息，四种生命周期

01 / STATE

任务事实

系统保存的当前进度、候选集、权限与执行结果。

02 / CONTEXT

当前视图

为一次模型决策临时组装，调用结束后可重建。

03 / MEMORY

跨会话偏好

需要置信度、纠正、过期和遗忘规则。

04 / RAG

外部知识

从受治理的知识源按问题检索，再注入 Context。

07 / 09
MEMORY IS NOT CHAT HISTORY

记忆必须经历四个治理动作

01

写入

判断是否稳定、是否属于本人。

02

读取

只在与当前任务相关时召回。

03

修正

当前明确表达优先于旧偏好。

04

遗忘

过期、敏感或被否认的信息删除。

RAG vs Real-time Tool
08 / 09
KNOWLEDGE IS NOT LIVE STATE

“查资料”和“查现在”必须分开

R RAG
检索知识

适合商品说明、选购知识、售后政策、使用指南。

  • 来源是文档与知识库
  • 重点是相关性与时效治理
  • 结果作为 Context
T LIVE TOOL
查询现在

适合实时价格、库存、物流、订单和支付状态。

  • 来源是真实业务系统
  • 重点是权限、成功与失败
  • 结果更新 State
