TRAJECTORY · LONG-TERM MEMORY · BUSINESS STATE · KNOWLEDGE

不同信息，放在不同层

01 / TRAJECTORY

本次运行历史

用户消息、模型回复、工具结果按时间追加，只增不改。

02 / USER MEMORY

跨会话稳定信息

从多次交互中提炼，会被改写、合并和淘汰。

03 / BUSINESS STATE

任务逻辑阶段

如需要澄清、处理中、等待付款或请求完成。

04 / RAG

共享知识管道

检索相关片段，将外部知识注入当前上下文。

KNOWLEDGE IS NOT LIVE STATE

“查资料”和“查现在”必须分开

R RAG
检索知识

适合商品说明、选购知识、售后政策、使用指南。

  • 来源是文档与知识库
  • 重点是相关性与时效治理
  • 结果作为 Context
T LIVE TOOL
查询现在

适合实时价格、库存、物流、订单和支付状态。

  • 来源是真实业务系统
  • 重点是权限、成功与失败
  • 结果更新 State
Correction · Recovery Ladder
08 / 09
THE NORMAL PATH IS NOT ENOUGH

确认无法恢复前，不暴露中间态

01

静默重试

临时超时先在框架内部有限重试。

02

接续生成

模型输出中断时，从已有轨迹继续。

03

回退稳定态

异常后回滚到上一可验证状态。

04

熔断停止

连续错误达到阈值，停止重复尝试。

05

人工干预

持续失败或高风险操作交还人类。

06

明确停止条件

完成、超预算或不可恢复时结束循环。
