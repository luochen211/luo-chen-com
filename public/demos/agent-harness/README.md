# Agent Harness 讲师演示台

一个与 37 页《Agent 与 Harness 基础课》同步使用的课堂演示应用。它由讲师操作，不是发给学员自行闯关的学习产品。

PPT 负责建立概念；演示台只在关键节点把抽象机制变成现场可见的系统行为。每个演示严格围绕一个证明目标展开，并明确提示讲师应该让观众观察什么、最后落到哪一句结论。

六个章节与 PPT 完全同序：

1. PPT 01—05：判断“一次回答”和“完成任务”的边界
2. PPT 06—12：逐步观察 LLM、Context、Tools 与 ReAct 轨迹
3. PPT 13—21：对比没有 Harness 和存在故障恢复时的结果
4. PPT 22—25：分类 State、Context、Memory、RAG 与实时 Tool
5. PPT 26—33：观察 Router 如何选择 Agent、Skill、Tool 或转交
6. PPT 34—37：真实运行六类任务变化并完成最小评测

每个演示均包含：

- 对应 PPT 页码与承接关系
- 讲师只需讲清的必要概念
- 本次演示唯一要证明的结论
- 讲师控制按钮与稳定的预设输入
- 三个需要引导观众观察的变化
- 演示结束后的一句话落点

应用不包含学员账号、课程进度、闯关或答题机制。保留的交互只服务于讲师控制演示节奏，例如逐步展开轨迹、注入工具故障和切换路由输入。
