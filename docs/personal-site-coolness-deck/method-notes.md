# Method notes

## 艺术字提示词反推

不要从“我要一个好看的字”开始，而是先拆视觉目标：

`字形结构 → 材质 → 光线 → 空间构图 → 色彩关系 → 时代/风格 → 禁止项`

例如：先说“窄长无衬线、金属氧化材质、侧上方硬光、黑色留白背景、橙蓝边缘光”，最后再补上“只保留一个词、不要 logo、不要多余文字”。生成结果后，再观察字形哪里成立、哪里失控，把结果反向写回下一版提示词。这就是提示词反推，而不是一次性碰运气。

## Cloudflare Pages 与国内访问

这套网站的交付链路是：Git push → Cloudflare Pages build → Pages deployment → custom domain。

“部署成功”只证明构建和 Pages 产物可用，不自动证明中国大陆所有网络环境都能稳定访问。需要分别核验：域名解析、HTTPS、缓存、IPv4/IPv6、运营商和地区访问，以及是否存在备案或合规要求。演示稿中把这一点单独拆出来，是为了区分工程交付和真实用户可达性。

## Remotion 的角色

Remotion 不是网站运行时，而是把 React 组件按时间轴逐帧预览和渲染成 MP4 的动态演示工具。当前 demo 用它表现“滚动叙事”的设计逻辑；真实网站本身仍使用 React、CSS sticky 和 GSAP ScrollTrigger。
