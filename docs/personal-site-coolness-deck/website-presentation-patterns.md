# 网站内容的呈现方式清单

这里说的“呈现方式”，指的是网页如何让内容出现、变化、移动和被理解——例如滚动叙事、渐进式信息披露，而不是内容目录、业务功能或组件分类。

## 一、空间与位置

### 1. 滚动叙事 Scrollytelling

用户向下滚动，内容按照章节、场景或事件推进。适合讲一个有明确起承转合的故事、案例或方法。

网站呈现：滚动到不同区间时，标题、图片、背景、数字或关系图依次变化。每一段只推进一个观点。

### 2. 固定舞台 Sticky Stage

页面继续滚动，但中间的核心视觉暂时固定，旁边的文字负责驱动它变化。

网站呈现：左侧固定一张产品界面，右侧滚动解释输入、处理、结果；或固定一张图，随着段落高亮不同区域。

### 3. 视差 Parallax

不同层以不同速度移动，制造前后景深和空间感。

网站呈现：背景纹理慢速移动，主图正常移动，前景标签略快移动。适合封面、空间结构和视觉过场，不适合承载关键文字。

### 4. 横向滚动 Horizontal Scroll

用户纵向滚动页面，但内容在某一段转为横向展开。

网站呈现：案例卡、作品集、时间节点或连续画面横向经过视口。移动端应保留自然横滑，不能只做桌面端的缩小版。

### 5. 无限画布 Infinite Canvas

内容不再是单列页面，而是一个可以平移、缩放、探索的空间。

网站呈现：知识地图、系统架构、作品关系、项目全景。必须提供当前位置、缩放控制和“回到主线”，否则用户容易迷路。

### 6. 分屏与多视口 Split Screen

同一屏同时展示两个或多个内容面，形成对照或关联。

网站呈现：左边是问题，右边是结果；左边是代码，右边是实际界面；上面是原版，下面是改版。窄屏时改为上下顺序。

## 二、内容出现与隐藏

### 7. 渐进式信息披露 Progressive Disclosure

先展示最必要的信息，用户继续操作后再看到细节、背景、例外和证据。

网站呈现：摘要 → 展开详情 → 查看原始证据。适合复杂内容，但不能把核心结论藏在第三层。

### 8. 折叠与手风琴 Accordion

多个内容块默认收起，用户点击后展开；通常用于 FAQ、方法解释、长列表。

网站呈现：一屏展示问题标题，点击后展开答案。适合查阅，不适合讲述必须连续阅读的主线。

### 9. 标签页 Tabs

多个平级内容放在同一个空间里，通过切换标签查看。

网站呈现：`概念 / 实操 / 复盘`、`原版 / 改版 / 说明`。标签之间应当是平级选项，不要把有先后关系的内容硬做成 Tabs。

### 10. 抽屉与侧栏 Drawer

主页面保持稳定，补充内容从侧边或底部进入。

网站呈现：点击某个数据点，右侧打开来源、注释或代码；适合辅助信息、详情和引用，不适合放唯一的核心内容。

### 11. 弹层与聚焦 Modal Focus

暂时离开主页面，把用户带入一个聚焦阅读或观看状态。

网站呈现：图片放大、视频观看、单页 PPT 阅读、重要证据核验。必须容易关闭，并支持返回原来的阅读位置。

### 12. Hover Reveal / Focus Reveal

鼠标悬停或键盘聚焦后，补充文字、图层、按钮或局部细节出现。

网站呈现：作品卡悬停显示项目类型，地图节点显示摘要，图片显示标注。触摸设备不能依赖 hover，必须有点击或默认状态。

## 三、内容切换与对照

### 13. 轮播 Carousel

多个内容共享一个展示位，用户通过箭头、圆点、拖拽或自动播放切换。

网站呈现：PPT 预览、案例截图、推荐内容。要显示当前位置和总数量，自动轮播要能暂停。

### 14. 滑块对照 Before / After Slider

用户拖动分隔线，在同一位置查看两个版本。

网站呈现：设计改版、网站前后、数据变化、原始素材与最终产物。适合视觉差异明显的内容。

### 15. 状态切换 State Transition

不移动到新页面，而是在同一场景里切换对象的状态。

网站呈现：`输入 → 运行 → 成功 / 失败`、`未选择 → 已选择`、`开始前 → 完成后`。适合演示系统如何工作，切换时要同步更新标题和说明。

### 16. 过滤与重排 Filter / Sort / Reorder

用户改变筛选条件，页面中的内容集合或顺序发生变化。

网站呈现：按主题、年份、项目类型筛选 PPT；按难度、时间、状态重排案例。变化应该有过渡，但不能用动画掩盖结果变化。

### 17. 逐帧切换 Frame-by-frame

一组画面随着滚动、点击或拖拽逐帧替换，制造动画或过程记录。

网站呈现：产品从草图到成品、界面逐步搭建、一个动作的分解。适合少量关键帧，帧数过多会影响加载和可维护性。

## 四、时间与节奏

### 18. 时间轴 Timeline

按时间、版本或阶段排列内容，让用户理解先后关系。

网站呈现：项目历程、个人成长、产品版本、课程进度。既要能顺着看，也要能直接点击某个节点。

### 19. 章节跳转与锚点导航 Anchor Navigation

页面保留一条可见目录，用户可以直接跳到任意章节，同时知道当前所在位置。

网站呈现：PPT 网页版、长篇案例、课程讲稿。它是滚动叙事的补充，让用户拥有“跳读”能力。

### 20. 滚动吸附 Scroll Snap

滚动停止时自动吸附到完整的卡片、屏幕或章节边界。

网站呈现：全屏网页 PPT、作品卡、横向展览。适合边界清晰的内容，不适合长段正文，否则会让阅读感觉被页面接管。

### 21. 自动播放与手动控制 Autoplay / Manual Control

内容按时间自己推进，也可以由用户点击、键盘或滚轮控制。

网站呈现：首屏电影感预览、演讲模式、产品 Demo。自动播放只能作为辅助，必须提供暂停、跳过和减少动画的方式。

## 五、文字、图形与媒介

### 22. 动态排版 Kinetic Typography

文字本身通过大小、位置、遮罩、错位、逐字出现或速度变化表达节奏。

网站呈现：一句核心判断分成几个词依次出现，关键词放大或改变位置。文字变化必须服务于语义，不要让每个标题都“飞进来”。

### 23. 数字与图形的实时变化 Data Motion

数字、图表、进度或关系线随着页面状态变化。

网站呈现：计数器、趋势线、节点亮起、进度条、指标对比。需要说明数据口径和起止值，避免只有视觉上的数字跳动。

### 24. 图像遮罩与裁切 Reveal Mask

图片、视频或界面通过圆形、线性、局部窗口或纸张边界逐渐显现。

网站呈现：封面过渡、作品局部放大、界面从黑屏启动、证据从某一区域展开。适合控制注意力，不适合反复遮住正文。

### 25. 视频与实时演示 Embedded Demo

直接展示一段真实操作、交互结果或现场记录。

网站呈现：网页内嵌视频、可操作 Demo、录屏与旁白并置。视频旁边应有文字摘要和关键时间点，避免用户只能从头看完。

### 26. WebGL / Canvas / 3D 空间

用实时绘制、粒子、三维物体或空间镜头制造非平面体验。

网站呈现：粒子组成的关系图、可旋转的产品模型、光场背景、三维场景转场。它适合做氛围和空间隐喻，关键内容仍应有 HTML 文本替代。

### 27. 声音与触觉反馈 Sound / Haptic Feedback

用声音、音量、节拍或设备震动强化状态变化。

网站呈现：演示模式中的提示音、完成任务时的反馈、视频和章节节奏。默认关闭或低打扰，并尊重用户的静音和减少动画设置。

## 六、组合方式示例

这些方式可以组合，但每一层只承担一个作用：

```text
首屏：动态排版 + 图像遮罩
主线：滚动叙事 + Sticky Stage
细节：渐进式信息披露 + 抽屉
对照：分屏 + Before / After Slider
导航：章节锚点 + 过滤重排
演示：状态切换 + 视频 / 实时 Demo
收尾：时间轴 + 下一步跳转
```

## 七、怎么选

| 想让用户感受到什么 | 优先考虑 |
| --- | --- |
| 内容正在发生 | 滚动叙事、状态切换、逐帧切换 |
| 内容有空间关系 | Sticky、视差、分屏、无限画布 |
| 内容有层级 | 渐进式披露、折叠、抽屉、弹层 |
| 内容需要比较 | 分屏、对照滑块、标签页 |
| 内容需要探索 | 横向滚动、过滤重排、关系图 |
| 内容有时间顺序 | 时间轴、章节跳转、滚动吸附 |
| 内容需要气氛 | 动态排版、遮罩、视频、WebGL、声音 |

最终不要追求“把所有方式都用一遍”。一份网站 PPT 通常选择 2–4 种主要呈现方式，再用少量辅助方式补充层级、导航和证据。判断标准是：用户是否因此更清楚地理解内容，而不是页面是否看起来更忙。
