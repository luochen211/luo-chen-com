# Design system

- Atmosphere: 深色编辑部、电影分镜、数字档案馆；克制但有张力
- Palette: near-black #070809; ink #F4F1E9; warm orange #DF7138; electric blue #2B8CA5; paper #EFE9DD
- Typography: oversized editorial Chinese headlines, compact uppercase English labels, generous negative space
- Grid: 16:9, wide margins, asymmetric editorial composition, one dominant idea per slide
- Recurring motif: thin rules, numbered chapters, circular/linear progress markers, cropped visual frames
- Image language: abstract UI fragments, cards, light fields, layered paper, browser-window silhouettes; no generic stock photos
- Motion language: reveal, hold, cover, orbit, expand; each motion must clarify a content transition
- Anti-patterns: rainbow gradients, excessive neon, random 3D objects, dense paragraphs, fake code screens, decorative motion without meaning
